# AI Growth Workflows 🤖

Production-ready prompt architectures, competitive intelligence automations, and LLM-assisted workflows designed for modern growth marketing and demand generation teams.

---

## 🛠️ Core Workflows

### 1. Ad Creative & Angle Generation
* **System Prompt:** B2B Copy Architect
* **Input:** ICP persona profiles, product release notes, competitor landing page copy.
* **Output:** 10 multi-angle creative variants across pain-point agitation, metric-driven proof, and contrarian points of view.

### 2. Answer Engine Optimization (AEO) Audit
* **Objective:** Track how generative search engines and LLMs (ChatGPT, Gemini, Perplexity) categorize, summarize, and recommend your software category.
* **Framework:** Prompt-based query matrices monitoring category mentions, product strengths, and competitor comparison results.

### 3. CRO Teardown Engine
* **Input:** Full-page screenshot and landing page value proposition text.
* **Analysis:** Structural scan evaluating message-to-market match, visual hierarchy, cognitive load, and friction points across the post-click flow.
